# webrec

## Run inside Codespaces

1. Install dependencies: `npm install`
2. Start the dev server (binds to all interfaces for port forwarding): `npm run dev`
3. Open the forwarded port 3000. The live preview URL follows this pattern:

```
https://3000-$CODESPACE_NAME.${GITHUB_CODESPACES_PORT_FORWARDING_DOMAIN:-app.github.dev}
```

Codespaces will also show an "Open in Browser" button for the forwarded port.
